# Composants tiers

La licence Apache 2.0 de ce projet ne remplace pas les licences des dépendances. Conserver les notices et fichiers de licence des composants redistribués.

Licences relevées dans les packages installés pendant la remise en état :

| Composant | Licence déclarée |
| --- | --- |
| Next.js | MIT |
| React | MIT |
| Radix UI (`@radix-ui/react-dialog`) | MIT |
| Lucide React | ISC |
| Geist (polices) | SIL Open Font License |

L’interface contient des composants selon les conventions shadcn/ui/Radix. Ce tableau est un repère, pas un inventaire exhaustif. Les dépendances directes et transitives exactes sont décrites dans les deux lockfiles npm ; leurs notices originales se trouvent dans les packages installés. Avant de redistribuer un bundle, vérifier et inclure les notices de tous les composants qu’il contient.
