# Contribuer

Commencer par l’installation du README. Décrire une reproduction précise : rôle utilisé, écran, requête, résultat attendu et résultat obtenu. Utiliser uniquement des personnes et adresses fictives dans les captures, fixtures et exemples.

Pour une modification, expliquer le problème, garder le changement limité et exécuter les trois commandes de vérification du README. Si une dépendance change, mettre à jour le lockfile npm correspondant. Ne jamais contourner une erreur TypeScript avec `ignoreBuildErrors`.

Les parcours nécessitant MySQL doivent être testés sur une base jetable. Avant une pull request, vérifier les accès enseignant/étudiant, les erreurs réseau, les formulaires au clavier et le comportement sur mobile. Mentionner ce qui n’a pas pu être testé.

Le projet est proposé sous Apache 2.0 après confirmation des droits par le propriétaire. Les contributions sont soumises à cette licence. Ne pas introduire de code tiers sans vérifier sa compatibilité et préserver ses attributions.
